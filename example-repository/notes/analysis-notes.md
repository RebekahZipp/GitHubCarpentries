# Analysis notes

## Question

Which day in this fictional sample has the highest number of library visits?

## Evidence

The source is `data/library_visits.csv`.

## Decision

Keep the raw fictional values unchanged. Any summary or visualization should be treated as generated output rather than replacing the source data.

## What we still do not know

This example does not tell us who visited, why they visited, or whether these five days represent a typical week.

That missing context matters. A repository can preserve a calculation without proving that an interpretation is complete.
